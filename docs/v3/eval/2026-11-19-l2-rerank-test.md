# L2 검색 평가: 모델 재순위 (2026-11-19, test-v1)

`app.v3.eval.retrieval --split test`를 `V3_EVAL_L2_AZURE=1 V3_EVAL_L2_RERANK=1`로 돌렸다(로컬에서 Azure AI Search 평가 전용 색인 `rsai-evidence-eval-l2`와 Foundry gpt-5-mini를 불렀다). 백엔드 커밋 2a32433.

S7·S8은 검색 순위의 상위 40개를 gpt-5-mini(추론 강도 low)가 질의에 맞는 순서로 다시 줄 세운 것이다(`app/v3/evidence/rerank.py`). 모델은 후보 번호만 고르고, 고르지 않은 후보는 원래 순서대로 뒤에 둔다. 상위 후보 수와 프롬프트, 점수 방식은 개발셋(dev, 40질의)만 보고 정했고 시험 질의는 정한 뒤 한 번 쟀다. 이 측정에서 모델 호출이 실패해 원래 순위로 답한 질의는 0건이다.

운영 배포(Azure 연결)는 2026-11-19부터 S8이고, 주 지표도 S8이다.

## 덧붙임

- 말뭉치 399건(종류별 {'assumption': 13, 'law': 374, 'ref': 12}), 그 가운데 평가 전용 법령 348조(law.go.kr 본문, sets/corpus/laws_extra.json).
- 주 지표는 운영 구성(S8, 검색 + 모델 재순위)이다. 답 있는 질의 66개, 답 없는 질의 14개.
- 정답 등급은 한 사람(초안)이 근거 원문을 읽고 매겼다. 이중 라벨과 κ는 아직 재지 않았다.
- S0은 법령만 보므로 기준값 질의의 정답(가격조사, KAU, 가정값)을 찾을 수 없다.
- S1(BM25F)의 동의어 표(evidence/synonyms.ko.json)와 무게는 개발 질의로만 정했고, 시험 질의는 고친 뒤 한 번 쟀다. S1v1은 고치기 전의 S1이다(같은 질의, 같은 말뭉치).
- S7·S8은 개발셋(dev)만 보고 정했다(상위 후보 수, 프롬프트). 시험 질의(test-v1)는 정한 뒤 한 번 쟀다. 모델 호출이 실패해 원래 순위로 답한 질의 0건.
