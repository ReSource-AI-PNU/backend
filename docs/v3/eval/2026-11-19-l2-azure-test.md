# L2 검색 평가: Azure AI Search 포함 (2026-11-19, test-v1)

`app.v3.eval.retrieval --split test`를 앱 VM의 백엔드 컨테이너에서 `V3_EVAL_L2_AZURE=1`로 돌렸다(평가 전용 색인 `rsai-evidence-eval-l2`, 제품 색인은 건드리지 않음).
임베딩은 Foundry text-embedding-3-small(1536차원)이고, 5만 자가 넘는 조문이 있어 벡터는 앞 5,000자로 만들었다(글 검색 필드에는 전문). 이 조건은 2026-11-19부터 제품 색인(search_azure.EMBED_MAX_CHARS)과 같다.

이 측정으로 ③ 규정 검토의 조항 검색을 S0(낱말 수 세기)에서 근거 검색으로 바꿨다. Azure가 연결된 배포에서는 S6(로컬 BM25F + Azure 하이브리드·시맨틱, RRF), 아니면 S1이다.

## 단서

- 말뭉치 397건(종류별 {'assumption': 12, 'law': 374, 'ref': 11}), 그 가운데 평가 전용 법령 348조(law.go.kr 본문, sets/corpus/laws_extra.json).
- 주 지표는 개발셋 nDCG@10으로 고른 방식(S1)이다. 답 있는 질의 66개, 답 없는 질의 14개.
- 정답 등급은 한 사람(초안)이 근거 원문을 읽고 매겼다. 이중 라벨과 κ는 아직 재지 않았다.
- S0은 법령만 보므로 기준값 질의의 정답(가격조사, KAU, 가정값)을 찾을 수 없다.
- S1(BM25F)의 동의어 표(evidence/synonyms.ko.json)와 무게는 개발 질의로만 정했고, 시험 질의는 고친 뒤 한 번 쟀다. S1v1은 고치기 전의 S1이다(같은 질의, 같은 말뭉치).
