# 에이전트 모듈

대회 6단계를 전문 에이전트 6개로 구현한다. 파일 하나가 단계 하나를 맡는다.

| 파일 | 단계 | 입력 | 출력 |
|---|---|---|---|
| `classify.py` | ① 식별·분류 | 사진·영상, 성분표 PDF | 품목, 재질, 수량, 이물질 종류와 비율 |
| `feasibility.py` | ② 가능성 판단 | ① 출력 | 오염 등급, 납품 가능 형태, 제거 권고 1건 |
| `regulation.py` | ③ 규정 검토 | 품목, 성분, 거래 계획 | 순환자원 해당 여부, 체크리스트, 조항 인용 |
| `matching.py` | ④ 업종·기업 탐색 | 품목, 수량, 위치 | 묶음 수거 후보, 처리업체 후보 |
| `cost_carbon.py` | ⑤ 비용·탄소 비교 | 후보 경로 | 경로별 비용, 순 탄소, KAU 환산액 |
| `proposal.py` | ⑥ 최적안 제안 | ①~⑤ 종합 | 추천안 1개, 대안 2개, 견적 요청서 초안 |

오케스트레이션은 `orchestrator.py`가 맡고, 단계 사이의 데이터 계약은 `app/schemas.py`에 정의한다.
